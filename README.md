# Teste App UNIMAPP

Projeto acadêmico desenvolvido em Python com Tkinter para o evento Jovem Programador — Bootcamp 2026.

O UNIMAPP é uma tela de login demonstrativa inspirada no contexto universitário da UNIMAR. Ele permite criar contas locais, entrar com usuário e senha e escolher o tipo de conta: **Aluno** ou **Professor**.

## Recursos utilizados

- Interface gráfica com Tkinter;
- `Frame`, `Label`, `Entry`, `Button` e `Radiobutton`;
- Funções e condições `if`, `elif` e `else`;
- Dicionário para organizar os usuários;
- Arquivo JSON simples para salvar as contas criadas.

## Como executar

Com Python instalado, abra um terminal nesta pasta e execute:

```bash
py unimapp.py
```

Se necessário, tente:

```bash
python unimapp.py
```

## Conta de teste

Quando ainda não existe um arquivo de usuários, o app disponibiliza:

```text
Usuário: aluno
Senha: 1234
```

> Este é um projeto demonstrativo local. Não use senhas reais e não há integração com sistemas oficiais da UNIMAR.
